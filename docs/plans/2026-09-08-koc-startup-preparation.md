# 养号启动检查：安装与登录

## 行为

每次浏览养号运行先执行一次独立准备任务，再依次执行搜索和首页浏览。准备任务使用现有小红书 login、官方市场安装和短信验证技能：先打开应用，明确未安装时进入官方市场安装，未登录时按现有手机号验证码流程处理；已登录则验证个人主页后直接继续。评论任务保持独立审核流程，不自动安装或登录。

准备任务仅授权目标应用、官方市场、系统安装器、默认短信和系统弹窗；浏览任务继续使用原有应用权限。准备阶段禁止浏览互动、评论、发布、私信、资料修改及付费。手机的 `account.login` 策略不会将 `installSourcePolicy` 解析为安装策略，因此官方市场范围同时依靠显式角色白名单、禁止浏览器下载及安装技能约束。

没有可靠手机号、验证码不可得、身份验证或其他需人工处理的情况会停止当前运行和同设备排队任务。手机号应直接在手机确认或填写，不通过任务文本或 guidance 传输。手机 `CALL_USER` 会提前返回并可能在等待超时后继续，因此控制器使用返回的确切 taskId 定向取消该任务，不使用 `current`。

## 状态及恢复

- 浏览运行在创建及启动时先检查账号资料：昵称、100 字以内简介、已选头像和背景图齐全，并有服务端记录的人工校验确认。手动开始、定时调度、旧 planned 记录均不能绕过。完整的历史已应用资料兼容此检查；普通账号写入不能伪造确认或应用元数据。
- 可选 `run.preparation` 独立保存状态、固定原因码和说明、任务 ID 与开始/完成时间；不保存原始登录消息、步骤、截图或短信内容。旧运行记录保持兼容。
- 仅成功任务的严格 `PREPARATION_JSON` 回执同时包含 `status:ready`、`code:ready`、`profileVerified:true` 才允许浏览。其后仅兼容手机自动追加的一条精确格式动作回执；其他尾随内容、无回执、格式错误、失败任务宣称 ready 均停止。
- 成功终态缺少有效回执时，控制器最多派发一次只读个人主页复核，不重放安装、登录或验证码。Android 对 `account.login` 且明确要求该回执的任务校验 COMPLETE：无效格式最多纠正两次，仍无效则失败；不能从自然语言或动作 note 补造 ready。
- 历史 `login_required` 不再阻止新的浏览运行做准备检查；账号受限和操作频繁仍形成跨重启的当日停机，准备阶段也会记录这些原因。浏览期间再次掉登录会立即结束本轮，不循环登录。
- 取消立即停止后续派发；已接收的准备任务等待返回后收口。准备过程中的账号限制不会因取消而丢失。
- 人工介入先持久化运行状态和确切任务 ID 再定向取消，存储失败也会尝试取消。控制器重启会取消已记录的遗留人工介入任务，并将准备状态标为中断，不重放安装、登录或验证码请求。限制/限流原因不会被人工介入、取消失败或重启抹掉。只有完整成功的运行允许继续设备队列。
- 准备不计入浏览篇数、互动额度或关键词表现。运行卡片和复盘详情显示启动检查状态。

2026-09-09 补充：浏览期间的 `CALL_USER` 同样先持久化确切任务 ID，再定向取消并停止后续任务块。Tabby-control 取消 RPC 只有收到手机 `aborted` 终态才报告成功，最多等待 15 秒；未确认时保留任务占用，不能提前标空闲。控制器恢复也必须保留未确认任务的隔离，暂时上报 idle 不能绕过。`USER_CANCELLED` 映射为取消，账号受限及限流原因优先保留。设备历史仅白名单保留控制面状态/原因码，原始登录内容继续脱敏。

聊天助手通知失败与手机任务结果分别处理。今天的会话曾出现模型 HTTP 522，但手机继续工作；该错误不能当作手机任务已停止的证据，实际进度以运行卡片及手机终态回执为准。

## 验证与边界

专项回归覆盖成功顺序、失败及人工处理、严格回执、短信内容脱敏、队列停止、取消竞态、当日停机、重启恢复和浏览权限隔离。设备历史中登录任务的原始结果亦需脱敏，RPC 原始结果仅供服务内存解析。

验证结果：Controller 114 个文件、1184 项通过；新增准备流程专项 28 项、设备历史专项 13 项通过；Web 相关 3 个文件、30 项通过；根目录测试 1074 项通过、38 项跳过。`pnpm generate-types`、`pnpm typecheck`、本轮 13 个代码/测试文件的 Biome 和 `git diff --check` 通过。全仓库 lint 仍受既有状态/缓存文件和 `nexu-config-store.ts` 两项规则问题阻塞。桌面进程及渲染窗口可访问；本轮未执行真机安装或验证码登录。

个人主页证据只证明当前手机已登录，不等于验证了运营人设与真实平台账号身份一致；目前没有可信平台账号身份字段，不用运营 label 猜测身份。手机号不可获取、滑块、实名或人脸验证仍需人工处理。自动安装与验证码登录的真机成功率需在具备相应前置条件的设备上验收，不能由桩测试推断。
